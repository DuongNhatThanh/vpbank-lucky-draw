# VPBank Lucky Draw

Hosted React + TypeScript + Vite scaffold for the VPBank Lucky Draw MVP.

## Local Setup

```bash
npm install
npm run dev
```

## Canonical Commands

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
- `npm run build`

## Current Scope

Foundation only. No draw logic, participant logic, persistence, audio, animation, XLSX import, backend, or database yet.
