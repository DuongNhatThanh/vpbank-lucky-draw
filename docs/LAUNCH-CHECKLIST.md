# VPBank Lucky Draw — Launch Checklist

## 1. Day Before

- [ ] Confirm the latest GitHub commit and successful Vercel deployment.
- [ ] Keep the repository, installed dependencies, roster source, and audio assets on the operator laptop.
- [ ] Confirm the production URL and the designated browser profile.

## 2. Before Venue Setup

- [ ] Open the production URL.
- [ ] Resolve any saved-session prompt intentionally.
- [ ] Load or paste the roster, preview it, and Apply Participants.
- [ ] Review all six prizes.

## 3. AV / Projector Check

- [ ] Open Presentation and check the VPBank logo and event title.
- [ ] Verify 1920x1080 and 1366x768 readability with no scrolling.
- [ ] Confirm four digits, current prize, and Grand Prize treatment are clear from a distance.

## 4. Participant Check

- [ ] Confirm four-digit codes preserve leading zeros.
- [ ] Confirm invalid and duplicate counts are zero.
- [ ] Keep the source roster available separately.

## 5. Browser / Vercel Check

- [ ] Confirm `npm run build` passed for the deployed revision.
- [ ] Confirm the VPBank logo and all five audio assets load.
- [ ] Remember recovery is limited to this device and browser profile.

## 6. Audio Check

- [ ] Turn Sound On after a user interaction.
- [ ] Hear countdown tick, draw start, reveal complete, winner confirmed, and Grand Prize sounds.
- [ ] Check volume with the ballroom AV system.
- [ ] Turn Sound Off and confirm the draw still works.

## 7. Fullscreen Check

- [ ] Enter and exit Fullscreen.
- [ ] Confirm browser Escape exits cleanly.
- [ ] Confirm fullscreen denial does not stop the raffle.

## 8. Recovery Drill

- [ ] Save a pending winner, refresh, and Resume Previous Session.
- [ ] Confirm the same code, prize, attempt, and participant status return.
- [ ] Confirm a completed event is not offered as recoverable.

## 9. Six-Prize Rehearsal

- [ ] Run all six prizes end to end.
- [ ] Rehearse Mark Absent & Redraw for one prize.
- [ ] Confirm six distinct winners and preserved absent history.

## 10. Go-Live Procedure

- [ ] Apply the final roster.
- [ ] Continue to Live Draw.
- [ ] Open Presentation, enter Fullscreen, and verify Sound.
- [ ] Keep the MC live workflow on Presentation Mode for the whole prize flow.
- [ ] For each prize: Start Draw, Complete Countdown, Select Winner, wait for Presentation to finish the reveal automatically, then Confirm Winner or Mark Absent & Redraw.
- [ ] Use Next Prize only after confirmation.

## 11. Emergency Procedures

- [ ] Refresh: choose Resume Previous Session.
- [ ] Presentation closes: reopen Presentation from operator view.
- [ ] Sound or fullscreen fails: continue without it.
- [ ] Winner absent: Mark Absent & Redraw.
- [ ] Complete Reveal: use only when Presentation is not being used or automatic reveal completion is unavailable.
- [ ] Invalid saved data: do not delete it blindly; Start New only with organizer approval.

## 12. Post-Event

- [ ] Verify Event Complete shows six confirmed winners.
- [ ] Record the final results using the approved event process.
- [ ] Clear local event state only when the organizer intentionally authorizes it.
